# Amazon Clone

A front-end Amazon Clone built using HTML and CSS. This project replicates the basic user interface of Amazon, including the navigation bar, search section, hero banner, product cards, and shopping sections.

## 🚀 Features

- Amazon-style Navigation Bar
- Search Box with Category Selector
- Location Section
- Sign In & Cart Section
- Responsive Hero Banner
- Product Category Cards
- Hover Effects
- Clean UI Design
- Flexbox-based Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
